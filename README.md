# 双选会授权门户和场馆中转台

所有学生、作品及席位为合成资料。选席主页、会务交付单、授权页、领取弹窗和场馆中转台可由浏览器访问。场馆人员用时钟页面向前推进公告轮次，初始为 1。当前轮次可用于新办理，较早的公告可以按门户界面查历史。结束浏览器不会重置中转留件或公告。重启演练服务才回到初始轮次和投递记录。

## 门户公开说明

授权页按学生、席位、场次、用途列出公告中的作品、授权编号及修订。领取弹窗也各自显示这些数据，切换席位时可能先打开上次的领取页。“刷新授权与领取入口”可以使入口跟上当前公告。下载清单仅显示当前可领部分，显示摘要指 TXT 原件字节的 SHA-256。领取页因授权修订或发布时刻不同可能暂缺作品。作品领取和交付窗的截止公告轮次均不含当轮。主页显示本轮剩余领取次数。达到名额后本轮不能再取，新一轮恢复名额。相同作品的不同授权上下文各有可核对的领取凭据。

场馆交付单给当前发布的席位和必需作品。替代单表示同一学生原实名派发的接收席变化。匿名必需作品以场单识别，可另有授权附加作品。成员文件名是领取页作品代号加 .txt。场单里发布的是业务领取条件，门户不会主动替会务取消或通知旧席。

## 中转台

中转台可以通过逐件文件上传，按投递号回查其交付单、授权编号与成员。提交时填写办理号、投递号、交付单和授权编号。同一投递号可以向相同派发上下文追加成员，已有成员维持原收件地点与摘要。办理号用来定位一次表单的响应，相同号可原样重送，改内容要使用新的办理号。转到主页且一时查不到办理回条时仍可查投递中的已收成员。

撤回或联系清除填新的办理号、原投递号及需处理的完整成员文件名。中转留存能由中转撤回，席位已收需要联系对应席位清除，表格只在席位回报后显示“席位已清除”。投递被部分接受时各成员状态互不替代，其他场次及用途的收件独立。中转台只记下实际办理动作，不替会务判断应在何时由哪个席位领取。

## 运行

依赖版本见 `requirements.txt`。浏览器演练使用 Playwright 配套的 Chromium。

```sh
python3 -m pip install -r requirements.txt
python3 -m playwright install --with-deps chromium
python3 portfolio_portal.py --port 8040
python3 -m unittest discover -s tests -v
```
